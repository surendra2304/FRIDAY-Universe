## How each gate is measured (read the verdicts with these)

- **Caption-track** — the VYR-045 gate (`viral_quality.caption_track_gate`) over the deployed vision sampler (`scene_analysis.sample_render_caption_detections`). Vision API key IS configured on the server (56-char value in the deployed .env — presence only, never printed). Sampler paces vision calls >= 65 s apart and the loop daily vision budget is 180k tokens, so only 5 renders got the vision measurement (823/841/861 — the known doubled-caption class — plus controls 824 and 801), at reduced density (3.0 s interval, max 12 frames = 4 requests each, ~20 requests total, ~6454 input tokens each). The other 6 renders report `caption_gate_unmeasured` — fail-closed, never a pass. The sampler hit HTTP 429s (Groq ITPM 7000/min; one OTPM "request too large" on output tokens) and retried within its bounded ladder (max 3 retries + one fail-over attempt); all 5 measured renders still produced verdicts.
- **Caption gate overcounting — read this before using the numbers.** The gate counts distinct visible texts, and it counts the designed framing/title layer and the source video's own burned-in text as caption tracks, and a wrapped caption as two lines. Frame-verified this run (see Findings): 801 shows 3 lines at 1.5 s, 823 shows 3 lines at 4.5 s, 841 shows 2 lines at 20 s, 824 shows 1 speech line at 22.5 s, 861 shows 1 line at 10 s. The gate numbers (4/3/3/4/5) therefore OVERCOUNT the true speech tracks — the FAIL direction is frame-confirmed for 801, 823 and 841, but 824 is NOT doubled-speech (single speech track + framing title + source text) and 861's count of 5 was not confirmed at the sampled instant. Follow-on work: refine the gate to exclude the framing band and match detections against the .ass speech timings (new task, not this one).
- **BGM presence** — VYR-047 method: ffmpeg volumedetect RMS per segment, voiced stretches from the .ass speech timings (hook/title layers excluded) vs voiceless gaps (>= 0.5 s). Pass iff every voiceless gap measures above the -45 dBFS floor AND no silence interval from the loudness scan falls in a voiceless stretch. Limit, stated plainly: RMS confirms audible non-voice energy in the gaps, not the bed's identity — the gap energy can include source audio. The manifest `bgm_source` is the corroboration for what that energy is. When the speech union tiles the whole render there is no gap to measure: then any silence interval is itself the absence evidence, and with neither a gap nor a silence interval the gate is `bgm_unmeasured` (the bed cannot be separated from the voice by this method).
- **Watermark** — ffprobe format-comment marker `vyralx-provenance:<record_id>` (the visible layer) + LSB extraction attempt on 3 sampled frames per render (`provenance_watermark.extract_payload`). Pass iff the marker is present. The LSB payload does not survive re-encoding, so it is reported, never required. No produce-path caller sets the marker today — the column is expected absent.
- **Loudness** — `media_quality.analyze_media_signals` (ffmpeg ebur128): pass iff integrated loudness in [-24, -10] LUFS and true peak <= -1.0 dBFS. `clipped_samples` is None on the deployed scanner (VYR-060 evidence) — carried as None, never invented, never a pass/fail input.
- **.ass corroboration (NOT the render verdict)** — `ass_caption_tracks` is the max simultaneous speech events in the sibling .ass file (hook layer excluded, override tags stripped). The .ass files do NOT reflect the renders' burned captions: 823/841/861 tile cleanly in the .ass (1 track) while the vision gate finds 3–5 tracks burned in the render, and cycle-2 .ass files (801–804) show overlapping speech events (2) with no recorded render defect. The .ass column is file-level evidence only; the vision verdict + frame checks are the render's caption verdict where measured.

## Findings (read before the table is used as a release list)

1. **No render passes all four gates.** Every render fails at least the watermark column; the 5 vision-measured renders all fail the caption gate; 3 renders fail true peak. Nothing in the pool is releasable as-is on this table.
2. **823/841 doubled confirmed first-hand (frame).** 823 @4.5 s shows 3 lines with an extra line beyond the .ass caption; 841 @20 s shows 2 speech lines at once. Both are watch-confirmed doubled renders; the gate's FAIL direction is right. RE-RENDER stands for both.
3. **801 is multi-line too — a NEW finding.** 801 is KEEP with no recorded defect, but its frame @1.5 s shows 3 caption lines at once and its .ass has overlapping speech events (2 simultaneous, overlaps up to 1.28 s). The gate's count of 4 overcounts (framing/source-text lines), but the multi-line FAIL is real. 801 needs a re-render decision by Muse — it was filed KEEP on the absence of a recorded defect, and the measurement now records one.
4. **824 is NOT doubled-speech — the gate overcounts here.** Frame @22.5 s shows 1 speech line; the .ass is a single speech track + framing title. The gate's 3 = closing title + speech line + a text not in the .ass ("TURN OFF THE CAMERA" — source-video text or a misread). 824's caption failure is a gate-counting artifact, not a doubled render. It DOES fail loudness honestly (true peak -0.2 dBFS, the worst in the pool), so it still fails overall — but not for captions.
5. **861's count of 5 is not frame-confirmed.** Frame @10 s shows a single clean line. The watch confirmed 861 doubled (three layers, two speech tracks ~1s out of sync), so the FAIL direction stands, but the number 5 is inflated by framing/duplicate reads. Its BGM gate is unmeasured (speech tiles the render, no silence interval) — the watch's no-BGM finding is NOT confirmed or refuted by this measurement; it stands as the human verdict.
6. **True-peak failures on 803 (-0.6 dBFS), 804 (-0.9 dBFS), 824 (-0.2 dBFS)** — all three KEEP renders, all over the -1.0 dBFS bar. LUFS passes everywhere (-12.5..-14.8). A true-peak fail is a level fix on re-render, not a release blocker the watch can waive without noting it.
7. **Watermark absent on all 11 renders (marker + LSB).** Expected — no produce-path caller sets the marker — but it means the whole pool fails that column. Follow-on work (mark at produce time) belongs to a new task, not this one; the column is filed, not skipped.
8. **BGM unmeasured on 802/803/825/861 (speech tiles the render, no silence interval).** The bed cannot be separated from the voice there by this method. 802/803 record `synth_fallback` BGM; the watch should weigh the synth bed when watching. 9. **The VYR-045 caption gate overcounts on real renders.** It counts the framing/title layer, source-video text, and wrapped lines as caption tracks, and at reduced density it merges sequential captions into one window. First real-render application of the gate; it has never passed a real render in production (the loop is OFF since Nov 21; VYR-045 merged after). Follow-on: refine the gate to exclude the framing band and match detections against the .ass speech timings. The gate is used here as implemented — the numbers above are its verdicts, with the frame analysis alongside.
