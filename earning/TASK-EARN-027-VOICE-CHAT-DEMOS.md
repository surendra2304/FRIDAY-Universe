# TASK-EARN-027 — CometWorks voice/chat agent service package

CometWorks service: AI voice + chat agents for local businesses (clinics
first). The demos are the proof; this file is the package that sells them.
Filed 2026-11-25 by Muse 10. Prices are **starting points** — the owner
sets final prices before any listing goes live.

## The demos (built in this task)

- **Demo 1 — clinic appointment voice agent** (OmniDimension pattern):
  a caller phones the clinic, the agent answers in English, Hindi or
  Telugu, books the appointment from the clinic's own services list, and
  the booking lands as a lead + follow-up in Cortex CRM. Worked example
  in the tests: Spotlight Dental, Banjara Hills — Root Canal Treatment,
  Friday 27 November 2026, 11:00 AM.
- **Demo 2 — website chat agent that books appointments** (Voiceflow
  pattern): a visitor chats on the business's website, the agent books
  from the same services list, same CRM landing. Worked example:
  Dentaire, Banjara Hills — routine check-up, Saturday 28 November 2026,
  4:00 PM.

Both demos run on the F-35 method: the agent's system prompt is generated
from the business's own services text, and the agent never invents
services, prices or timings. Live answer/call tests on the free tiers are
the gated follow-up (see `docs/collaboration/TASK-EARN-027.md`); until
they run, pitch drafts reference the demos by name and the live demo URL
is added once the demo is deployed (deployment needs Muse's hub clearance).

## Price points

- **Setup fee: $149 one-time** per business — prompt built from the
  business's own services, voice + chat agents configured, CRM landing
  wired, one live test call + one live test chat filed as proof.
- **Monthly care: $49/month** — prompt updates when services change,
  missed-call review, monthly booking report, small wording tweaks.
- First-money path: the first business setup fee.
