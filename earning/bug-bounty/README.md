# Bug-Bounty Lane — Methodology Pack (Preparation Only)

**Owner order 2026-11-25: pursue the bug-bounty lane.** This pack prepares the lane
to the point where the only remaining step is the owner's one-time account creation
on the chosen platforms. **This pack is preparation only: no testing of any live
target has been done or is authorised by this document.** All practice happens on
the legal practice platforms in the 30-day plan; all real testing happens only
inside a named programme's published scope, after the owner creates the accounts
and the coordinator confirms the programme's rules.

## Why this lane, honestly

Bug bounties are real income — companies pay security researchers who find and
responsibly report vulnerabilities in their systems. They are also the slowest,
most skill-gated lane in the CometWorks portfolio: most beginners earn nothing for
months, payouts are per-valid-report (duplicates and out-of-scope findings pay
$0), and the first realistic money is a small bounty ($50–$500) after the learning
period. The 30-day plan exists to find out — cheaply, legally, in free labs —
whether this lane deserves more investment before any serious time is committed.

## The exact accounts the owner must create (one-time, all free)

Create these once, with the CometWorks Gmail, username **cometworks** where the
platform allows it. This is the complete list — nothing else is needed to start.

1. **HackerOne** — hackerone.com → Sign Up (hacker profile). The largest public
   programme directory; where the first real programme will be chosen.
2. **Bugcrowd** — bugcrowd.com → Researcher sign up. Second programme source;
   its Bugcrowd University material is free training.
3. **PortSwigger Web Security Academy** — portswigger.net/web-security → free
   account. This is the main practice ground for the 30-day plan (free, legal,
   purpose-built vulnerable labs).
4. **Hack The Box** — hackthebox.com → free account (free tier / Starting Point
   machines are the practice range). Optional but recommended.
5. **Intigriti** and **YesWeHack** — create only when the 30-day plan finishes
   and a specific programme there is chosen; both are free for researchers,
   Intigriti is invite/approval-based for some programmes.

Payment setup (only when the first bounty is awarded): HackerOne pays via PayPal
or bank transfer; the owner adds payout details inside the platform at that time.
No platform on this list charges researchers anything, ever — any "bug bounty"
site asking for a signup fee is a scam; walk away (free-only rule).

## First-money path (realistic)

Days 1–30: free labs only (zero income, zero risk) → coordinator go/no-go review →
owner accounts confirmed → pick ONE beginner-friendly public programme with a
wide, clearly-written scope → hunt low-severity, high-probability issue classes
first (the plan names them) → first valid report → first bounty. Expected time to
first money if the lane works: 2–4 months. If the 30-day review says the skill
isn't landing, the lane pauses and the faster lanes (Fiverr, Contra) keep the
December target — that honesty is built into the plan on purpose.
